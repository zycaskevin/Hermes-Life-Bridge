**Release:** HLB v0.4.0

**Canonical parent:** HLB-004.7 Failure Injection & Automatic Recovery

## Long-running maintenance

HLB now bounds operational trace growth with a multi-process-safe rotating JSONL trace:

```text
10 MiB current
+ 3 backups
```

Defaults are configurable through:

```text
HLB_TRACE_MAX_BYTES
HLB_TRACE_BACKUP_COUNT
```

Rotation uses a process-shared file lock and all trace/current/backup/lock files remain mode `0600`.

Daily maintenance is installed through:

```text
hermes-life-maintenance.timer
```

The maintenance task:

- checkpoints/truncates operational SQLite WAL files;
- purges old terminal Percept/Cognition reliability rows after the configured retention window;
- compacts OperationStore when rows are purged;
- deliberately does **not** automatically purge Contact duplicate-prevention/reconciliation records.

Default Percept/Cognition terminal retention:

```text
30 days
```

## Real wall-clock soak

A genuine 1h/24h/72h soak cannot be truthfully completed inside the development container because it requires Nancy's live:

- Hermes Gateway;
- Life Runtime;
- Hermes API;
- systemd workers;
- real route lifecycle;
- actual restart/load behavior.

The release therefore includes:

```text
scripts/soak_hlb004.sh 1
scripts/soak_hlb004.sh 24
scripts/soak_hlb004.sh 72
```

The monitor records component health, route status, unresolved operation counts, and operational file sizes once per minute without enabling proactive Contact.

These runs are **deployment acceptance**, not unfinished code development.

## Release installer

`scripts/install_on_hermes.sh` is rollback-capable.

Before replacement it backs up:

- existing HLB plugin tree;
- HLB environment file;
- existing HLB systemd units.

It records service enabled/active state, stops HLB workers, installs into a new plugin tree/venv, then starts the new workers.

On failure before final success it restores the previous plugin/config/unit files and previously active services.

External Contact delivery is forcibly reset to:

```text
false
```

on every install/upgrade.

The installer runs:

- HLB self-test;
- 1,000-event accelerated soak gate;
- service/socket readiness checks;
- an automatic `hermes gateway restart` attempt.
