# HLB-001.1 — Receipt / Migration Consistency

Real Gateway E2E proved transport success but exposed three consistency defects:
- old `nancy-live-runtime` plugin remained enabled;
- Runtime returned `safe_stop`;
- Bridge labeled an unpersisted SafeStop ACK as `STATE_ADVANCED`.

HLB-001.1:
- parses Runtime `persisted` explicitly;
- emits `STATE_ADVANCED` only for persisted non-duplicate transitions;
- emits fail-visible `STATE_NOT_ADVANCED` for non-persisted SafeStop;
- requires the old plugin to be disabled and moves its source directory to a timestamped backup outside active plugin discovery.
