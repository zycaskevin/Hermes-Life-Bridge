# HLB-003.4 — Deterministic Privacy Acceptance Ordering

Fixes the HLB-003.3 false fail caused by running the canonical final byte scan after HLB services had restarted and could append trace records.

Canonical order:
1. stop/quiesce all HLB trace writers;
2. synchronously re-run privacy migration/sanitization;
3. run deterministic byte-level verifier while writers remain stopped;
4. emit canonical privacy PASS markers;
5. only then install/start services;
6. perform read-only health checks.

No Gateway reload and no provider send are required.
