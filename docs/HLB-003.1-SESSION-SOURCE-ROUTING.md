# HLB-003.1 — SessionSource Routing Hotfix

The first authorized HLB-003 real-send attempt reached `HERMES_SEND_START` but failed because
the Bridge had serialized an entire `SessionSource(...)` object into the `--to` target.

Hermes exposes structured route fields. HLB-003.1 uses:
- platform value
- chat_id
- thread_id
- message_id

Canonical targets:
- `platform`
- `platform:chat_id`
- `platform:chat_id:thread_id`

For Feishu, chat_id is the conversation/reply destination.

Privacy:
- exact target is kept only in `last_route.json` mode 0600;
- normal trace records only platform and `route_ready`;
- real-send E2E refuses to guess a target and requires a route learned from a real Gateway message.
